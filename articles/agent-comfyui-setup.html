Agent 时代 ComfyUI 部署指南

ComfyUI · Agent 自动化 · Hermes · 新手入门 · 配套最新整合包（cu130）

说清意图，让 Agent 自己动手——你只管决策，它管实现。

这是 ComfyUI 入门配置的 Agent 时代版本，配套 GaryAIGC 最新整合包（内置 CUDA 13.0 / Python 3.12 / 最新前端，开箱即用）。和老教程相比，你不用再手动装 Git、Python、CUDA、cuDNN、ffmpeg——整合包全部自带。你只需要做 3 件手动的事：装显卡驱动、下载解压、开代理，剩下的交给 Agent。

核心思路：说意图，不写代码

1. 手动：装驱动 / 下载 / 开代理 → 2. Agent 探测环境 → 3. Agent 配置启动器 → 4. Agent 启动验证 → 5. 人工确认出图
🤖 Agent 接管

你不需要告诉 Agent 具体路径、具体命令、具体版本号。只需描述目标，Agent 会自动扫描你的电脑：找到整合包、检测显卡驱动、识别代理端口，然后生成适配你机器的脚本并执行。

👤 人工把关

涉及物理机操作、账号权限、重启、肉眼确认的节点，Agent 无法替代。全流程只有 3 个手动步骤 + 1 次最终确认，其余全部交给 Agent。

⚠️ 核心约束（全程有效）：整合包使用便携版 Python（位于 python_embeded 目录）。所有 pip 安装、依赖修复，必须使用便携 Python，禁止写入系统 Python。给 Agent 的指令里这句话一定要带。

👴 不会用 Agent？走传统图文教程：ComfyUI 入门环境配置图文教程

第 1 步：下载并解压整合包 👤 手动

整合包托管在夸克网盘，Agent 无法自动登录你的网盘账号下载。请手动完成：

下载地址：https://pan.quark.cn/s/b5509d5c360f（B站老许分享-Comfyui整合包-老许8月轻量包，不含模型）

解压密码：为防恶意贩卖，压缩包已加密——密码请到老许粉丝群「群公告」自取（找不到进群方式看站内「社区」页）。

解压要求：解压到非中文路径（例如 D:\ComfyUI，路径里不能出现中文和空格）——老教程血泪教训：路径带中文会出各种奇怪问题，排查起来很痛苦。

注意：解压后请确认目录里有 python_embeded 文件夹（整合包的便携 Python 环境），有它才是完整包。

第 2 步：安装显卡驱动 + 开启虚拟内存 👤 手动

这是唯一必须手动安装的软件。整合包内置 CUDA 13.0，需要较新的 NVIDIA 驱动，建议直接安装官网最新版 Studio 驱动：

① 打开 NVIDIA 官网驱动下载 → 选择你的显卡型号 + Windows → 下载 Studio 驱动（比 Game Ready 更稳定）

② 安装过程屏幕可能黑屏闪烁，属正常；装完必须重启电脑

③ 重启后：右键「此电脑」→ 属性 → 高级系统设置 → 性能设置 → 高级 → 虚拟内存 → 改为「自动管理」（容易爆显存就手动设 20GB+）

✅ 怎么验证驱动装好了？ 按 Win+R 输入 cmd 回车，输入 nvidia-smi，能显示显卡信息表格就说明驱动正常。

第 3 步：开启网络代理 👤 手动

ComfyUI 更新节点、下载模型需要访问 GitHub / HuggingFace，国内网络需要代理。请确认你的代理软件（Clash Verge / v2rayN 等）已开启系统代理或TUN 模式：

① 打开代理软件 → 开启「系统代理」

② 记下你的代理端口号（Clash Verge 默认 7897，其他常见 7890/10809）——告诉 Agent 时要用到

③ 不会开？用 Clash Verge 的话，设置 → 系统代理开关打开即可；再不行问群友/Agent

第 4 步：让 Agent 帮你搞定一切 🤖 Agent 接管

完成上面 3 个手动步骤后，打开 Hermes（推荐，桌面版体验最好；Kimi Code / Claude Code 也可以），把下面这段话复制给它。它会自己找整合包、检测环境、配置启动器、启动验证。

🤖 复制给 Agent 的第一句话 
请帮我完成 ComfyUI 整合包的部署配置。先做环境探测：
1. 扫描电脑上所有 ComfyUI 整合包目录（含 python_embeded 的就是），确认位置、大小、版本
2. 检测：显卡型号、驱动版本（运行 nvidia-smi）、显存、Windows 版本、磁盘剩余空间
3. 检测代理：读取系统代理设置，确认代理端口号
4. 输出《环境就绪报告》，每项标注 [就绪]/[缺失]/[需升级]

绝对约束：
- 我是整合包用户，所有 Python 操作必须用整合包自带的 python_embeded\python.exe，禁止动系统 Python
- 不需要安装 Git / CUDA / cuDNN / ffmpeg / 系统 Python（整合包已内置）
- 如果驱动版本过低，告诉我需要手动升级到最新 Studio 驱动（这步我不能自动做）
🤖 报告确认后，复制给 Agent 的第二句话 
基于刚才的《环境就绪报告》，继续完成配置：
1. 确认整合包解压位置正确（非中文路径），检查 python_embeded 存在
2. 用整合包自带的启动脚本（启动.bat 或官方 run 脚本）配置代理端口，端口用我系统代理的实际端口
3. 启动 ComfyUI，等待出现 http://127.0.0.1:8188，确认界面正常
4. 用浏览器验证 8188 端口可访问，加载默认工作流能正常出图
5. 输出《安装完成验证清单》

绝对约束：全程使用 python_embeded 的便携 Python；改任何配置前先备份；每完成一大步输出状态让我确认
💡 Agent 会做什么：扫描磁盘找整合包 → 检查驱动/代理 → 写启动配置 → 启动服务 → 验证端口 → 汇报。你只需要在它问你"驱动版本对吗？"的时候回答，或者让它继续。

第 5 步：人工验证与收尾 👤 人工确认

Agent 跑完后，你要肉眼确认这几件事：

① 浏览器打开 http://127.0.0.1:8188，ComfyUI 界面正常加载（暗色界面 + 左侧节点面板）

② 加载默认工作流 → 点「Queue Prompt」→ 能正常出图

③ 启动日志没有红色报错（驱动/显存相关报错见下方排查表）

④ 装插件：告诉 Agent「帮我在 ComfyUI-Manager 里安装 XX 插件」，它会用便携 Python 装依赖

模型从哪来？（重要）

⚠️ 本整合包不含模型（为控制体积，网盘标注「轻量包·不含模型」）。你需要自己准备模型文件，放进整合包 ComfyUI\models 对应子目录：
  • checkpoints — 主模型（如 SDXL / Flux 等，根据你想玩的类型下载）
  • diffusion_models — 扩散模型（视频类，如 MiniMax H3）
  • vae — VAE 文件
模型获取渠道：模型文件另行分享——关注老许粉丝群公告 / 网盘「模型」目录（也可以让 Agent 帮你从 HuggingFace 下载，需要代理）。模型放对目录后，直接让 Agent「扫描我的 models 目录，告诉我缺哪些模型」即可。

故障排查：Agent 报错怎么办？

报错现象责任方解决方案
nvidia-smi 不是内部命令👤 人工驱动没装好或没重启。回到第 2 步，装完重启再试。
CUDA out of memory👤 人工显存不足。虚拟内存开大一点，或用低显存模式启动。
Failed to initialize NVML👤 人工驱动过旧或损坏。装官网最新 Studio 驱动，重启。
git clone 超时 / 443👤 人工代理没生效。确认代理软件系统代理开启，端口写对。
ModuleNotFoundError: No module named 'xxx'🤖 Agent大概率包装到了系统 Python。 告诉 Agent：「请检查这个依赖装到了哪里，如果是系统 Python，卸载并重装到整合包的 python_embeded 里。」
模型加载失败 / 文件损坏👤 人工模型没放对目录或下载不完整。确认放在 models 对应子目录，重新下载。

附录：给 Agent 的指令速查

指令 A：探测环境（不安装）

扫描我电脑上所有 ComfyUI 整合包和系统环境（显卡/驱动/磁盘/代理），输出《环境就绪报告》标注 [就绪]/[缺失]/[需升级]。注意：我是整合包用户，用 python_embeded 便携 Python，不需要装 Git/CUDA/系统 Python。

指令 B：配置并启动

基于环境报告，配置整合包启动器的代理端口（用我系统代理实际端口），启动 ComfyUI 到 http://127.0.0.1:8188，浏览器验证能出图，输出验证清单。绝对约束：只用 python_embeded，改配置先备份。

指令 C：装插件

帮我在 ComfyUI-Manager 安装插件「XXX」。用整合包的 python_embeded 装依赖，禁止写系统 Python。装完重启验证节点出现在节点列表。

指令 D：修复包装错位置

我遇到 ModuleNotFoundError，怀疑依赖装进了系统 Python。请检查最近安装的包位置，如果在系统 Python，迁移到整合包 python_embeded 并验证。

总结：Agent 时代装 ComfyUI，其实只有 3 件手动事

✅ 手动（3 件）：装驱动（必做）、下载解压（必做）、开代理（必做）——都是系统级/账号级操作，Agent 替代不了。

✅ Agent（剩下全包）：探测环境、配置启动器、启动验证、装插件、修报错。

✅ 一条铁律：所有 Python 操作走 python_embeded，不碰系统 Python。
