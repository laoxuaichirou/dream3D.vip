AI 编程工具安装与配置实操手册

整理自实操记录，适用于 Windows 10/11 环境，目标路径以 G:\AIcoding 为例。

一、Claude Code 安装与第三方 API 配置（Windows）

1.1 前置条件

· 已安装 Node.js（自带 npm）

· 确认 npm 可用：npm -v

1.2 安装到非系统盘（G 盘）

步骤 1：创建目录并修改 npm 全局前缀

mkdir "G:\AIcoding\npm-global"
npm config set prefix "G:\AIcoding\npm-global"

步骤 2：安装 Claude Code

npm install -g @anthropic-ai/claude-code
若 PowerShell 报错 无法加载文件...因为在此系统上禁止运行脚本，请改用 CMD（命令提示符） 执行上述命令。

步骤 3：添加环境变量（永久生效）

1. Win + R → 输入 sysdm.cpl → 回车

2. 高级 → 环境变量

3. 下方「系统变量」找到 Path → 编辑 → 新建

4. 输入：G:\AIcoding\npm-global

5. 一路确定，关闭所有终端，重新打开

步骤 4：验证

Get-Command claude
claude --version

预期输出路径为 G:\AIcoding\npm-global\claude.cmd。

1.3 配置第三方 API（免登录方案）

Claude Code 默认要求登录 Anthropic 官网，国内网络受限。通过配置文件可直接调用第三方中转 API，跳过登录。

步骤 1：创建配置目录

在文件资源管理器地址栏输入：

%USERPROFILE%\.claude

若不存在，手动新建名为 .claude 的文件夹（注意前面的点）。

步骤 2：创建 settings.json

文件路径：C:\Users\<你的用户名>\.claude\settings.json

内容模板：

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的API Key",
    "ANTHROPIC_BASE_URL": "https://code.newcli.com/claude/ultra",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": 1
  },
  "permissions": {
    "allow": [],
    "deny": []
  }
}
注意：
- ANTHROPIC_BASE_URL 不要带 /v1/messages，Claude Code 会自动补全。
- 若平台文档写的是 super 而非 ultra，以平台文档为准。
- CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC 关闭遥测，避免向官方发心跳。

步骤 3：创建 .claude.json 跳过首次引导

文件路径：C:\Users\<你的用户名>\.claude.json

内容：

{
  "hasCompletedOnboarding": true
}

步骤 4：启动验证

claude

若直接进入交互界面（出现 > 提示符或项目选择），不弹出浏览器登录，即配置成功。

1.4 API 连通性测试（PowerShell）

若 Claude Code 启动异常，先用 PowerShell 测试 API 是否可用：

$headers = @{
    "Content-Type" = "application/json"
    "x-api-key" = "你的APIKey"
    "anthropic-version" = "2023-06-01"
}

$body = @{
    model = "claude-sonnet-4-6"
    max_tokens = 1024
    messages = @(
        @{
            role = "user"
            content = "hi"
        }
    )
} | ConvertTo-Json -Depth 3

Invoke-RestMethod -Uri "https://code.newcli.com/claude/ultra/v1/messages" -Method Post -Headers $headers -Body $body

结果解读：

· 返回正常 JSON（含 content、model、role）→ API 正常，问题在 Claude Code 配置

· 401 → API Key 无效或已过期

· 404 → Base URL 路径错误，尝试加/去掉 /v1 或换 super

· 503 → 平台服务端临时故障，等待或联系客服

1.5 常见问题

现象原因解决
`npm : 无法加载文件...禁止运行脚本`PowerShell 执行策略限制改用 CMD 执行 npm 命令
`claude` 命令找不到PATH 未配置或终端未重启检查环境变量，重开终端
启动后仍要求登录浏览器`.claude.json` 缺失或 `settings.json` 路径错误确认两个文件位置和内容
CC Switch 测试按钮报 503平台健康检查端点与 Claude Code 实际端点不同以 PowerShell curl 测试结果为准，忽略 CC Switch 测试按钮

二、Kimi Code 安装（Windows）

2.1 安装到 G 盘

步骤 1：设置环境变量并执行安装脚本

$env:UV_TOOL_DIR = "G:\AIcoding\uv"
Invoke-RestMethod https://code.kimi.com/install.ps1 | Invoke-Expression
若 Invoke-RestMethod 报错，改用 CMD 手动安装：先确保 uv 已安装，再执行 uv tool install --prefix "G:\AIcoding\uv" kimi-cli。

步骤 2：迁移可执行文件到 G 盘（若默认装到了 C 盘）

mkdir "G:\AIcoding\uv\bin" -Force
Copy-Item "$env:USERPROFILE\.local\bin\kimi*" "G:\AIcoding\uv\bin\" -Force

步骤 3：永久添加 PATH

$currentPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($currentPath -notlike "*G:\AIcoding\uv\bin*") {
    [Environment]::SetEnvironmentVariable("Path", $currentPath + ";G:\AIcoding\uv\bin", "User")
}

步骤 4：验证（关闭重开 PowerShell）

Get-Command kimi
kimi --version

预期输出：G:\AIcoding\uv\bin\kimi.exe。

三、Cursor 安装与汉化

3.1 安装选项建议

安装过程中「选择附加任务」建议全部勾选：

· ☑️ 创建桌面快捷方式

· ☑️ 将"通过 Cursor 打开"添加到文件上下文菜单（右键文件直接打开）

· ☑️ 将"通过 Cursor 打开"添加到目录上下文菜单（右键文件夹直接打开项目）

· ☑️ 将 Cursor 注册为受支持的文件类型的编辑器

· ☑️ 添加到 PATH（重启后生效）

3.2 安装中文语言包

步骤 1： 按 Ctrl + Shift + P 打开命令面板

步骤 2： 输入 Configure Display Language → 回车

步骤 3： 若提示无中文，点击 Install additional languages

步骤 4： 搜索并安装 Chinese (Simplified) Language Pack

步骤 5： 安装完成后点击右下角 Restart 重启 Cursor

Cursor 基于 VS Code，绝大多数 VS Code 扩展均可直接使用。

四、宝塔网站百度统计修复

4.1 获取统计代码

1. 登录 tongji.baidu.com

2. 进入站点管理 → 找到目标网站 → 代码获取

3. 复制新版统计代码（hm.baidu.com/hm.js?...）

4.2 插入代码到网页

目标位置： 所有需要统计的 HTML 文件的 </head> 标签前一行。

以宝塔面板操作为例：

1. 宝塔 → 文件 → 进入网站根目录 /www/wwwroot/dream3d.vip/

2. 双击编辑 index.html

3. Ctrl + F 搜索 </head>

4. 在 </head> 的上一行粘贴百度统计代码：

<script>
var _hmt = _hmt || [];
(function() {
  var hm = document.createElement("script");
  hm.src = "https://hm.baidu.com/hm.js?你的站点ID";
  var s = document.getElementsByTagName("script")[0]; 
  s.parentNode.insertBefore(hm, s);
})();
</script>

5. 保存，并对其他子页面（如 guides/index.html）重复操作。

4.3 验证

· 浏览器打开网站 → Ctrl + U 查看源代码 → 搜索 hm.baidu.com，确认存在

· 回到百度统计后台 → 实时访客 → 刷新网站，观察是否有新数据进入

五、ComfyUI 插件安装后检查

5.1 判断安装是否成功

通过 ComfyUI-Manager 安装插件后，观察日志：

· Extracted zip file to ... → 文件下载成功

· Install: pip packages → 依赖安装指令已发出（但未显示具体结果）

· After restarting ComfyUI, please refresh the browser → 必须重启

5.2 手动补依赖（Windows 便携版）

若重启后插件报错 ModuleNotFoundError，使用便携版自带 Python 安装：

G:\Comfyui\COMFYUI_Laoxu\python_embeded\python.exe -m pip install -r G:\Comfyui\COMFYUI_Laoxu\ComfyUI\custom_nodes\<插件名>\requirements.txt
不要用系统默认的 pip，否则依赖装到系统环境，ComfyUI 读不到。

5.3 清理残留

若日志提示 Renamed '...' to '.disabled/.trash/...' but could not delete：

1. 完全关闭 ComfyUI

2. 手动删除 ComfyUI/custom_nodes/.disabled/.trash/ 目录

3. 重新启动
