整合包下载说明

资源下载 · 夸克网盘 · 2026-08-06 更新
⚠️ 重要：整合包下载已拆分为两个链接（① 轻量整合包 + ② 模型自取），两个都要转存，只保存一个会缺文件用不了。

为什么拆成两个链接？

原来整合包和模型放在同一个网盘分享里，但夸克网盘的风控把其中 2 个文件（整合包压缩包 + 1 个模型）过滤掉了——你自己的网盘看得到，但粉丝通过分享链接打开时看不到、也保存不了。

所以重新拆分发布：整合包一个链接、模型一个链接，单独分享的文件不再被过滤，两个链接都是永久有效、无提取码。

两个链接分别是什么

① 轻量整合包（不含模型） ComfyUI_Gary2026_v3.7z · 约 3.6G https://pan.quark.cn/s/e98d1d2204c7 整合包本体：内置 CUDA 13.0 / Python 3.12 / 便携环境，不含模型。压缩包已加密，解压密码请到老许粉丝群「群公告」自取（找不到进群方式看站内「社区」页）。
② 模型自取文件夹（含 MiniMax H3） 模型合集 · 约 3TB 内容 https://pan.quark.cn/s/d577d1e7a801 全部模型文件：MiniMax H3、Qwen 系列、Flux、放大模型等，按文件夹分类。模型文件不需要密码，直接转存/下载。

安装流程（三步）

✅ 第 1 步：转存并下载两个链接的全部内容。
✅ 第 2 步：解压整合包到非中文路径（例如 D:\ComfyUI，路径不能有中文和空格），输入粉丝群公告里的解压密码。
✅ 第 3 步：把「模型自取」里的模型文件放入整合包的 models 目录对应子文件夹（checkpoints / diffusion_models / loras 等）。

常见问题

Q1：打开链接显示"文件被过滤"或看不到文件？

你打开的很可能是旧链接。请使用本页的两个新链接（①②），它们已单独分享、不会被过滤。

Q2：解压提示需要密码？

整合包压缩包已加密，密码在老许粉丝群「群公告」自取——群内免费提供，谨防倒卖。

Q3：模型放哪个目录？

大模型（safetensors）放 models\checkpoints 或 models\diffusion_models；LoRA 放 models\loras；不清楚具体放哪就放进 models 后让 Agent / 群友帮你看。

Q4：下载速度慢？

夸克网盘非会员有速度限制，属正常现象；可以开通夸克会员或错峰下载。
