点击图片可查看完整电子表格

1.2 复合对象与“黑盒”逻辑

IMAGE (像素空间)：

转换：必须通过 VAE Encode 才能变成 LATENT。

处理：如果你要改尺寸，必须用 Upscale Image，不能直接改连线。

LATENT (潜空间)：

转换：必须通过 VAE Decode 才能变回 IMAGE。

注意：不同模型的 LATENT（如 SD1.5 和 SDXL）通常不兼容。

CONDITIONING (条件向量)：

来源：由 CLIP Text Encode 产生。

组合：可以用 Conditioning Combine 把两个 Prompt 缝合，但不能把两条线直接插进一个端口。

ComfyUI 数据流语法与类型转换速查手册（新手深度版）

1 为什么 ComfyUI 必须区分数据类型

1.1 计算机的死板逻辑

1.1.1 节点就像不同形状的插头和插座

1.1.2 AI 不理解模糊指令：它无法直接把文字文字转化为图像，必须经过转换

1.2 颜色识别系统的意义

1.2.1 端口颜色是第一道防线：相同颜色代表数据格式一致

1.2.2 强制连接的后果：通常会直接导致执行红框报错，系统无法理解数据

2 基础数据类型：AI 处理的“基本零件”

2.1 STRING：字符串（文本）

2.1.1 端口颜色：浅绿色

2.1.2 什么是字符串

2.1.2.1 任何你输入的一段文字、字母或符号

2.1.2.2 例子：正向提示词（Prompt）、模型存放的磁盘路径、标签名

2.1.3 新手常见误区

2.1.3.1 你在 STRING 里写数字 512，它依然是文字，不能直接连到需要 INT 的尺寸端口

2.1.3.2 你在里面输入颜色代码 #FF0000，它只是一串符号，AI 不知道那是红色

2.2 INT：整数

2.1.1 端口颜色：浅蓝色

2.2.2 什么是整数

2.2.2.1 没有小数点的数字

2.2.2.2 例子：图片的分辨率（512, 1024）、采样步数（Steps）、随机种子（Seed）

2.2.3 必须遵守的规则

2.2.3.1 8 的倍数原则：在 Stable Diffusion 中，宽高必须能被 8 整除，否则报错

2.2.3.2 不接受小数：如果你把步数设为 20.5，系统会崩溃或强制报错

2.3 FLOAT：浮点数（带小数的数字）

2.3.1 端口颜色：蓝色

2.3.2 什么是浮点数

2.3.2.1 代表比例、强度或程度的数字

2.3.2.2 例子：CFG 面板（7.5）、重绘强度（Denoise: 0.7）、权重值

2.3.3 兼容性特征

2.3.3.1 向上兼容：你可以输入 1，它会自动变成 1.0 处理

2.3.3.2 向下排斥：FLOAT 接口无法直接连接到 INT 接口

2.4 BOOLEAN：布尔值（开关）

2.4.1 端口颜色：金黄色

2.4.2 什么是布尔值

2.4.2.1 只有两种状态：是（True）或者 否（False）

2.4.2.2 例子：是否启用某个插件、是否开启高清修复、是否保存图片

3 核心复合类型：AI 创作的“数据对象”

3.1 IMAGE：像素图像

3.1.1 端口颜色：蓝色（注意与 FLOAT 区分，通常点比较大）

3.1.2 本质

3.1.2.1 我们肉眼能看到的彩色图片数据

3.1.2.2 它是解压后的成品数据

3.1.3 处理逻辑

3.1.3.1 只能连接处理图片的节点，如：图片裁剪、图片放大、图片保存

3.2 LATENT：潜空间数据（隐藏层）

3.2.1 端口颜色：粉色/紫红色

3.2.2 本质

3.2.2.1 它是 AI 大脑里的“草稿”：经过压缩的、普通人看不懂的特征数据

3.2.2.2 潜空间比像素空间小得多，所以 AI 算得快

3.2.3 转换关键

3.2.3.1 必须通过 VAE Decode（解码）才能变回 IMAGE

3.2.3.2 必须通过 VAE Encode（编码）才能把普通图片塞进潜空间

3.3 CONDITIONING：条件引导（指令包）

3.3.1 端口颜色：黄色

3.3.2 本质

3.3.2.1 它是文字经过 CLIP 翻译后，打包给采样器的指令

3.3.2.2 它告诉采样器：在哪里画人，在哪里画树

3.3.3 常见组合

3.3.3.1 多个条件的缝合：通过 Conditioning Combine 将多个 Prompt 指令包合二为一

3.4 MODEL：加载的模型大脑

3.4.1 端口颜色：紫色

3.4.2 注意事项

3.4.2.1 这是整个流程的基础，通常来自 Checkpoint 加载器

3.4.2.2 如果不小心连错了，整个采样过程连启动都不会启动

4 强制类型转换：连线变红时的自救方案

4.1 为什么会连不上

4.1.1 情况一：精度不匹配（如 FLOAT 要连 INT）

4.1.2 情况二：格式不匹配（如 STRING 要连 COLOR）

4.1.3 情况三：维度不匹配（如 SD1.5 的模型要连 SDXL 的控制节点）

4.2 常用转换节点速查（需安装工具插件如 Utils 或 Impact Pack）

4.2.1 数字类转换

4.2.1.1 String to Number：将文字“512”转化为真正的数字 512

4.2.1.2 Int to Float：将步数整数转化为可计算的浮点权重

4.2.1.3 Float to Int：将带小数的参数强行修剪为整数

4.2.2 视觉类转换

4.2.2.1 Color Picker 节点：输出真正的 COLOR 数据，而非单纯的文字代码

4.2.2.2 Hex to RGB：将网页格式的色号转化为 AI 能读懂的三维数值

4.2.3 潜空间与像素转换（生死线）

4.2.3.1 VAE Decode：救命节点，当你发现最后一步不出图时，通常是漏了它

4.2.3.2 VAE Encode：当你做图生图时，图片必须经过它才能被 AI 重新“雕刻”

5 进阶避坑：关于数据流的“潜规则”

5.1 枚举选项（Dropdown）的陷阱

5.1.1 下拉菜单里的选项（如采样器名称）本质是特殊的 STRING

5.1.2 你不能随便连一个自己写的 STRING 进去，必须选择系统预定义的名称

5.2 隐式转换的危险

5.2.1 有些节点会悄悄把你的数据取整

5.2.2 建议养成：在关键连接处加一个 Note（注释），提醒自己这里是什么数据类型

5.3 理线建议

5.3.1 Reroute（理线器）不仅是为了美观

5.3.2 它可以作为“数据检查站”：鼠标停留在理线点上，可以看到当前流过的数据类型和具体数值1.1 基础类型与连接规则
