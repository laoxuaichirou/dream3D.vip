ComfyUI 插件安装与更新（简化版）

ComfyUI · 整理自 Gary 的教程文档

安装/更新插件简化版本丨直接用！

安装/更新插件简化版本，直接用！

1.设日期格式：

for /f "tokens=2 delims==" %a in ('wmic os get localdatetime /value') do set "dt=%a"

set "date_str=%dt:~0,8%"

2.备份快照（整个整合包也建议手动备一份）

如果没手动备份环境文件的话，建议一个月或者半个月备份一次！

python.exe -m pip freeze > requirements-backup%date_str%.txt

3.更新插件用：git pull（安装插件用：git clone +git地址）

4.依赖安装（安全无冲突）

基于 --upgrade-strategy only-if-needed（官方推荐，99%场景满足需求）

预检：python.exe -m pip install -r （requirements.txt换成你自己的依赖文件） --upgrade-strategy only-if-needed --dry-run

查看输出：无报错、无核心库不必要变动 → 执行正式安装

正式安装：python.exe -m pip install -r （requirements.txt换成你自己的依赖文件） --upgrade-strategy only-if-needed

若预检报错：先手动修改 requirements.txt（如指定兼容版本），再重复上述步骤

完成后重启comfyui。

有问题把comfyui-user-comfyui.log内容发给AI，根据指导解决。

每次更新前跑一遍 ：

python.exe -m pip freeze > requirements-backup%date_str%.txt 来备份快照是必须的

出现问题回退：

python.exe -m pip install -r （requirements-backupYYYYMMDD.txt你备份的环境快照） --force-reinstall
