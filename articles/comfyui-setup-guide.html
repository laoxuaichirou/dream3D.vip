ComfyUI 入门环境配置图文教程

ComfyUI · 新手入门 · 31 张步骤配图

B站Comfyui环境配置（老版）

本文讨论了大炮满血comfyui整合包的配置指南，包括下载地址、环境变量设置、各项软件安装步骤、启动器魔法环境配置等内容，还介绍了软链制作的附加教程。关键要点包括：

下载地址：提供了满血包公开版的夸克网盘和百度网盘下载地址。

环境变量准备：必须做好环境变量，若之前是cuda12.8 且 python 版本为 312 或 313 则无需重复操作。

软件安装：依次要升级最新显卡驱动、安装 git、python、VisualStudio、cuda12.8、cudnn，解压 ffmpeg6.0 到指定路径，安装时多采用默认路径，注意 cuda 只能装 12.8，20 - 50 系显卡支持，类似 A100 不支持。

环境变量设置：电脑右键设置环境变量，检查路径是否存在后重启电脑。

文件解压与替换：将环境包解压到非中文目录，用网盘内的 models 文件夹替换主环境内的。

启动器魔法环境配置：comfyui 需要全程魔法，在 win 系统网络代理设置中查看端口号，介绍了官方启动器和秋叶设置。

软链制作：适用于多个 Comfyui 统一调度大模型，可节省硬盘空间，给出了使用方法示例。

首先，必须做好环境变量！很重要，不然肯定无法启动！

之前做过的，并且是cuda12.8的，就不需要做这些步骤了，python版本如果是312或者313，也不需要降级

01、升级最新显卡驱动，打开虚拟内存，重启电脑（这两步很简单，自行百度）

https://www.nvidia.cn/geforce/drivers/

显卡驱动注意最好是从官网输入自己显卡型号下载，不要用一些游戏软件自动下载

02、安装git，网盘下载的，默认安装，不要管弹什么，一直下一步，不要自定义路径

等待即可！

03、安装python，默认安装路径，注意勾选添加变量（之前如果装过python跳过这一步就可以，之前装的什么版本都无所谓，跟整合包不冲突）

别忘记勾选：添加环境变量！

04、安装VisualStudio，这里要注意，有勾选项目要求，一样的，默认路径不要改

装完重启！

05，安装cuda12.8，注意，只能装12.8，因为整合包内置的就是最高版，20-50系全系是支持12.8的。

注意：本整合包内置 CUDA 12.8，需驱动 ≥ 535；旧驱动（≤ 532）无论 20/30/40/50 系还是 A100 都会报错

06、安装cudnn，默认安装

07、解压ffmpeg6.0到指定路径，注意，一定不能套目录！！！好好检查

08、电脑右键，属性，高级系统设置，设置环境变量

逐条检查以上变量，确认路径存在，重启电脑（可手动复制我下面的，前提是你确实是默认路径安装）

这里不要过于死板，因为有时候你安装版本跟我不同，比如第一条路径是14.43.34808，可能你装的时候数字变成新版了，所以要自己举一反三，对照找到自己安装的版本
