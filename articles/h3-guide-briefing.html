H3 提示词指南 v1.2 信息简报

信息简报 2026-08-06 · 官方规范 + 社区实测

一句话

H3 的提示词不是"描述"而是"剧本"——官方把三字段/六字段语法翻译成 13 章可直接照抄的中文教程,含 5 个可直接复制的案例模板和 12 条翻车修复方案。

文档形态

单文件 HTML,暗色主题,目录导航 + 代码复制按钮。官方规范与社区实践明确分色标注。

完整版:👉 MiniMax H3 终极提示词指南(13 章完整版)

核心要点(30 秒版)

章节关键结论
结构Base 三字段(integrated_multimodal_description / overall_soundscape / non_diegetic_music);Ref2VA 六字段(多出 subject_definitions / summary / retention_analysis,第四字段官方名 detailed_description)
台词必须 <d>[Language] 原文</d>;标签内只放语言+台词,语气写外面;支持 11 种语言
中文防翻车中文提示词完全可用,但画面描述写像对话会被当台词念;无台词场景显式声明 No dialogue... lips remain completely closed
音频参考只传音色,必须配图/视频,干净人声,2-15 秒,≤15MB
镜头Motion Type + Amplitude + Speed;每片段一个主导运动,禁堆叠
retention 标签视觉:fully_preserved / partially_preserved / attribute_transfer / weak_reference;音频:fully_copy / partially_copy / reference / weak_reference(非官方词如 style_only 无效)
