RunningHub API 小白速通指南

不用写代码，不用懂技术，看完就能用。

>

适用对象：想用 AI 批量生图/生视频，但不想每次打开网页拖节点的人。

一、这东西是什么？我用它干嘛？

RunningHub 是一个云端 AI 创作平台，里面有别人搭好的「AI 应用」（其实就是 ComfyUI 工作流），你能直接调用来生成图片、视频、音频。

OpenClaw 是一个 AI 助手平台，你现在正在用的「小龙虾」就是跑在 OpenClaw 上的。OpenClaw 给小龙虾装了一个「RunningHub 技能包」，所以你直接跟我聊天就能调用 RunningHub，不用写代码，不用打开网页。

简单说：你在微信/Kimi/飞书里跟我说一句话，我就能帮你跑 AI 生成。

二、我需要准备什么？

就两样：

1. RunningHub 账号 + API Key

1. 去 runninghub.cn 注册账号

2. 登录后进入「企业 API」→「共享 API Key」

3. 创建一个 Key，复制下来（格式像：59dfca00xxxxxxxx）

4. 把 Key 发给我（小龙虾），我就能帮你调了

💡 安全提示：这个 Key 只代表你的 RunningHub 身份，不会泄露你的登录密码。但也不要随便发到公开群。

2. 充点钱（两种消费方式）

消费方式用途价格
**RH 币**AI 应用调用会员减免后约 20-50 RH 币/单
**钱包余额**标准模型 API、原生 ComfyUI按实际 GPU 时长计费

充会员更划算：会员状态下跑 AI 应用，走 RH 币 + 减免，钱包不动。实测一单花了 28 RH 币，人民币 ¥0。

不开会员也能用，但 AI 应用可能会直接扣钱包余额。

三、怎么收费？企业级和个人有什么区别？

RunningHub 的 API Key 分两种类型：

个人消费级 Key（NORMAL）

· 能干嘛：调用平台上已有的「AI 应用」（别人封装好的工作流）

· 不能干嘛：不能直接调文生图/文生视频的「标准模型 API」

· 扣费：RH 币（会员减免）或钱包余额

· 适合谁：大部分用户，够用

企业级共享 Key（ENTERPRISE）

· 能干嘛：上面所有 + 标准模型 API（直接调万相、可灵等）+ 原生 ComfyUI 接口

· 扣费：钱包余额（人民币）

· 适合谁：需要深度定制工作流、批量生产的专业团队

新手建议：先用个人 Key 跑 AI 应用，够用了。真有需要再升级企业级。

四、我在哪能用？

OpenClaw 支持很多渠道，你在哪聊，我就在哪帮你跑：

渠道状态
**Kimi（当前）**✅ 可用
**飞书**✅ 可用
**Discord**✅ 可用
**Telegram**✅ 可用
**Slack**✅ 可用
**微信**⚠️ 需要额外配置

场景举例：

· 你在飞书群里 @小龙虾：「跑这个应用，提示词改成赛博朋克城市」→ 我直接在群里返图

· 你在 Kimi 里跟我私聊：「批量生成 10 张电商产品图」→ 我跑完一张张发给你

五、Hermes 能不能用？

Hermes Agent 是另一个开源 AI 智能体（类似 OpenClaw 的竞品），也能自托管、支持多平台。

理论上 可以，但：

· Hermes 没有现成的 RunningHub 技能包，需要自己写插件

· OpenClaw 已经有现成的 RunningHub Skill，开箱即用

结论：如果你已经在用 OpenClaw（也就是现在的我），直接继续用就行。如果你在用 Hermes，需要有人帮你写个 RunningHub 工具插件才能对接。

六、我能用小龙虾跑哪些功能？

只要给我 API Key，下面这些我都能帮你做：

✅ AI 应用（推荐新手）

· 浏览平台上的热门 AI 应用

· 查看某个应用的可修改参数

· 修改提示词、尺寸、模型等参数运行

· 上传图片让工作流处理（换脸、换装、放大等）

✅ 标准模型 API（需要企业级 Key）

· 文生图（万相、Flux 等）

· 图生视频（可灵、Seedance 等）

· 文生视频

· 图片放大、视频放大

· 语音合成（TTS）、音乐生成

· 3D 模型生成

✅ 批量生成

· 同一提示词跑多张图

· 同一工作流换不同提示词批量跑

· 批量上传图片处理

✅ 辅助功能

· 查询账户余额（钱包 + RH 币）

· 查看进行中的任务

· 浏览/搜索 AI 应用

七、批量生成怎么办？

三种方式：

方式 1：让我手动跑（适合少量）

你跟我说：「用同一个应用，提示词分别改成 A、B、C，各跑一张」→ 我一张张帮你跑，一张张发。

方式 2：写脚本循环（适合中等批量）

我可以帮你写一个 shell 脚本，自动循环调用 API，生成 10 张、100 张都行。你只需跑一次脚本。

方式 3：工作流模板化（适合大量、固定流程）

你在 RunningHub 网页上搭一个工作流，导出 API JSON，我写个脚本批量替换里面的参数（提示词、模型、尺寸），自动提交。

八、常见问题 FAQ

Q1：我是不是只需要发 API Key 给你就行了？

是的。 把 Key 发给我，我就能帮你调 RunningHub 的所有功能。不需要你写代码，不需要你开网页。

Q2：API Key 安全吗？你会不会泄露？

· Key 只存在你的本地环境变量里，我不会主动存储

· 但为了安全，建议定期检查 RunningHub 后台的调用记录

· 如果发现异常，随时去 RunningHub 官网重置 Key

Q3：不开会员能用吗？

能。 但 AI 应用调用会直接扣钱包余额（人民币），没有 RH 币减免。充会员后，AI 应用走 RH 币 + 减免，成本低很多。

Q4：我本地有 ComfyUI 工作流，能搬上去吗？

能。 在本地 ComfyUI 导出 API JSON → 上传到 RunningHub → 发布为 AI 应用 → 拿到 webappId → 我就能帮你通过 API 调用。

Q5：生成的图版权归谁？

RunningHub 平台规定，生成内容的商用权利取决于使用的模型许可协议。一般来说，你自己生成的东西归你，但具体要看工作流里用的模型是否有特殊限制。

Q6：为什么有时候任务会失败？

常见原因：

· 提示词触发了平台安全策略（比如敏感内容）

· 上传的文件格式不对（只支持 jpg/png）

· 工作流本身有节点报错（去 RunningHub 网页版「我的任务」看详细日志）

· GPU 资源紧张，排队超时

Q7：我想跑视频，是不是很贵？

视频生成确实比图片贵，消耗更多 RH 币/余额。建议先用图片测试工作流效果，确认满意后再跑视频。

九、三步走，从 0 到出图

Step 1: 去 runninghub.cn 注册 → 创建 API Key → 发给我
Step 2: 跟我说 "看看有什么热门应用" 或 "跑这个应用 ID: xxx"
Step 3: 我返图给你，不满意就改提示词再跑

就这三步。没有 Step 4。
