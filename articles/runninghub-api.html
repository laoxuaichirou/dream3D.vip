RunningHub API 调用新手教程

基于真实实操记录整理。以下所有命令和环境变量均已在实际环境中验证通过。

>

适用场景：你有 RunningHub 账号，想通过代码/API 方式调用平台上已有的 AI 应用（ComfyUI 工作流），而不是每次都打开网页拖拽节点。

一、准备工作

1.1 获取 API Key

1. 登录 RunningHub 官网

2. 进入「企业 API」→「共享 API Key」页面

3. 创建 Key，复制备用（格式类似：59dfca00...）

4. 充值：AI 应用调用走 RH 币，标准模型 API 走 钱包余额。建议充会员，AI 应用调用有减免。

1.2 确认账户状态

把 Key 配到环境变量，然后跑检查：

export RUNNINGHUB_API_KEY=你的APIKey

# 检查账户状态
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub.py --check

预期输出：

{"status": "ready", "balance": "58.335", "currency": "CNY", "coins": "45458", "api_type": "NORMAL"}

· balance：钱包余额（标准模型 API 扣这里）

· coins：RH 币（AI 应用扣这里）

· api_type：NORMAL 表示个人消费级，ENTERPRISE 表示企业级

⚠️ 重要区别：NORMAL 类型的 Key 只能调用 AI 应用，不能调用标准模型 API（如文生图/文生视频等 endpoint）。只有企业级共享 API Key 才能调标准模型。

二、核心流程：调用 AI 应用

这是本教程的重点——调用平台上已有的 ComfyUI 工作流（AI 应用）。

2.1 获取应用信息

每个 AI 应用都有一个 webappId（应用 ID）。从应用页面地址栏复制，格式如：2045558582556499969。

export RUNNINGHUB_API_KEY=你的APIKey

python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --info 2045558582556499969

预期输出：

{
  "webappId": "2045558582556499969",
  "nodes": [
    {
      "nodeId": "49",
      "nodeName": "CR Text",
      "fieldName": "text",
      "fieldValue": "默认提示词...",
      "fieldType": "STRING",
      "description": "text"
    },
    {
      "nodeId": "21",
      "nodeName": "EmptyLatentImage",
      "fieldName": "width",
      "fieldValue": "1080",
      "fieldType": "INT"
    }
  ]
}

关键字段说明：

· nodeId：节点 ID，后续修改时用来定位

· fieldName：字段名，如 text（提示词）、width（宽度）

· fieldType：字段类型，STRING（文本）、INT（整数）、IMAGE（图片）等

· fieldValue：当前默认值

2.2 运行应用

基于上面的节点信息，你可以修改任意可修改的字段。最常见的场景是改提示词：

export RUNNINGHUB_API_KEY=你的APIKey

python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --run 2045558582556499969 \
  --node "49:text=你的提示词内容" \
  -o /tmp/openclaw/rh-output/result_$(date +%s).png

参数说明：

· --run：运行模式（区别于 --info 查询模式）

· --node "nodeId:fieldName=新值"：修改指定节点的字段。多个 --node 可以叠加。

· -o：输出文件路径。支持 $(date +%s) 自动生成时间戳，避免覆盖。

多字段修改示例：

python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --run 2045558582556499969 \
  --node "49:text=超写实风格，赛博朋克城市" \
  --node "21:width=1920" \
  --node "21:height=1080" \
  -o /tmp/openclaw/rh-output/result_$(date +%s).png

上传图片示例（如果工作流需要输入图片）：

python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --run 2045558582556499969 \
  --file "39:image=/path/to/your/photo.jpg" \
  --node "52:prompt=给图中人物换红色外套" \
  -o /tmp/openclaw/rh-output/result_$(date +%s).png

2.3 等待结果

AI 应用运行时间取决于工作流复杂度：

· 简单文生图：30-60 秒

· 复杂工作流（含放大、换脸、多节点）：1-5 分钟

· 视频生成：3-10 分钟

脚本会自动轮询任务状态，直到完成或失败。完成后会输出：

OUTPUT_FILE:/tmp/openclaw/rh-output/result_1234567890.png
DURATION:140s

如果工作流输出多张图，会有多个 OUTPUT_FILE 行。

三、费用与消耗

3.1 AI 应用调用

· 计费方式：RH 币

· 会员减免：消费级-会员 Key 有减免，实测一单约 20-50 RH 币

· 钱包扣费：¥0（会员状态下）

查看消耗：登录 RunningHub 网页 →「我的任务」→ 找到对应任务 ID，可看到明细：

· 原始费用、折扣、RH 币消耗

· 任务时长、GPU 规格

3.2 标准模型 API

· 计费方式：钱包余额（人民币）

· 适用 Key：仅企业级共享 API Key（api_type: ENTERPRISE）

· NORMAL Key 不支持：会报 NO_API_KEY 或权限错误

四、常见问题

Q1：提示 NO_API_KEY

环境变量没配好。确认：

echo $RUNNINGHUB_API_KEY

如果没有输出，重新执行 export RUNNINGHUB_API_KEY=你的Key。

也可以把 Key 持久化到 ~/.openclaw/openclaw.json：

python3 -c "
import json, pathlib
p = pathlib.Path.home() / '.openclaw' / 'openclaw.json'
p.parent.mkdir(exist_ok=True)
cfg = json.loads(p.read_text()) if p.exists() else {}
cfg.setdefault('skills', {}).setdefault('entries', {}).setdefault('runninghub', {})['apiKey'] = '你的Key'
p.write_text(json.dumps(cfg, indent=2))
"

Q2：提示 APP_INFO_FAILED

webappId 写错了，或者应用不是公开的。检查一下应用页面地址栏的数字。

Q3：提示 NO_NODES

这个应用需要先在 RunningHub 网页上成功运行至少一次，才能通过 API 调用。去网页上点一次「运行」，等出结果后再试 API。

Q4：任务失败了怎么办？

1. 检查提示词是否触发了平台安全策略

2. 检查上传的文件格式是否正确（图片只支持 jpg/png）

3. 检查节点参数类型是否匹配（不要给 INT 类型传字符串）

4. 去网页版「我的任务」看详细错误日志

Q5：如何找更多 AI 应用？

# 查看推荐应用（前 10 个）
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --list --sort RECOMMEND --size 10

# 查看最热门应用（近 7 天）
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --list --sort HOTTEST --size 10 --days 7

# 查看最新应用
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --list --sort NEWEST --size 10

输出包含 webappId、title、description，直接复制 ID 就能用。

五、完整示例：从 0 到跑出第一张图

# Step 1: 配 Key
export RUNNINGHUB_API_KEY=59dfca00xxxxxxxx

# Step 2: 检查账户
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub.py --check
# → 确认 status=ready，coins 充足

# Step 3: 选一个应用（比如 2045558582556499969）
# 先查它能改什么参数
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --info 2045558582556499969

# Step 4: 运行！改提示词
python3 ~/.openclaw/workspace/skills/runninghub/scripts/runninghub_app.py \
  --run 2045558582556499969 \
  --node "49:text=一只穿着宇航服的柴犬，站在月球上" \
  -o /tmp/openclaw/rh-output/my_first_image_$(date +%s).png

# Step 5: 等输出，下载图片
# → OUTPUT_FILE:/tmp/openclaw/rh-output/my_first_image_1234567890.png

六、进阶：原生 ComfyUI 接口（Workflow API）

如果你想完全自定义工作流，而不是调用别人封装好的 AI 应用，可以用 RunningHub 的原生 ComfyUI 接口：

https://www.runninghub.cn/proxy/你的APIKey

这个地址功能等同于本地 http://127.0.0.1:8188。你可以：

1. 在本地 ComfyUI 搭好工作流

2. 导出 API JSON（ComfyUI 菜单 → Save → API Format）

3. 直接 POST 到上面的地址

4. RunningHub 云端执行，返回结果

但这需要企业级 API Key，且需要自行处理轮询和文件下载。对新手来说，先用 AI 应用方式（上面的流程）更稳定。

七、总结

方式适用场景Key 类型计费
AI 应用（推荐新手）调用现成工作流NORMAL（消费级）RH 币
标准模型 API直接调用文生图/视频模型ENTERPRISE（企业级）钱包余额
原生 ComfyUI完全自定义工作流ENTERPRISE（企业级）钱包余额

新手建议路线：

1. 注册 → 充会员（AI 应用减免）→ 创建 NORMAL Key

2. 在网页上找到喜欢的 AI 应用，记下 webappId

3. 用 --info 查看可修改参数

4. 用 --run + --node 批量生成

5. 熟练后再考虑企业级 Key 和原生 ComfyUI 接口
