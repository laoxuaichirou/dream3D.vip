第01章一、版本定位

Seedance 2.5 已全量上线。定位：专业创作的新基准——“更长、更真、更听话，指哪打哪”。相对 2.0(支持图/视频/音频/文本四模态输入）的升级：从“导演体验”到“全能的专业数字片场”。

多模态参考优化的 10 个子能力

  • 🎵 分离/移除 BGM：提示词要求删除音乐背景音，仅留人声，同时保留原画面字幕等其他元素

  • 🎬 专业级白模控制：白模精准控制镜头调度、分镜设计、角色站位与运动轨迹

第05章五、提示词方法论（核心）

5.1 基础提示词写法

要素：场景描述 + 主体 + 时间戳分段 + 镜头语言 + 声音设计。

参考示例（自然纪录片）:

写实自然纪录片风格，电影级真实光影，清晨的薄雾中，在广阔的湿地芦苇荡@图片1里，一只优雅的丹顶鹤正展翅起舞。@图片2丹顶鹤羽毛洁白如雪，头顶鲜红，身姿修长挺拔，动作轻盈高贵。场景为秋季的浅水湿地，水面波光粼粼，周围长满金黄色的芦苇、浮萍与水草，虚化背景中是远处的晨雾与初升的太阳。镜头为低机位中景，轻微手持感，整体基本固定，始终保持丹顶鹤在画面中央。0s-3s：一只丹顶鹤静立在浅水中，身姿优雅。它刚开始缓慢地展开宽大的黑白双翼，动作轻柔，水面被翅膀扇动的气流带起阵阵涟漪。晨风吹拂，阳光从地平线斜射过来，穿透薄雾形成丁达尔光效。3s-8s：丹顶鹤在水面上轻盈跳跃，双脚交替点水，溅起晶莹的水花。它修长的颈部向后仰起，鸟喙指向天空，随后身体轻盈落地，收拢双翼恢复站立姿态，头部优雅地环顾四周，发出一声清脆的长鸣。低机位，轻微手持感，轻微跟随丹顶鹤的跳跃轨迹上下移动。景深自然，前景的芦苇轻微虚化，丹顶鹤主体清晰，背景的晨雾与朝阳柔和虚化。自然环境音，水流声、翅膀扇动时有力的扑击声以及鹤鸣声，整体宁静、空灵、唯美。

5.3 30 秒长视频写法

结构：【全局设定】+【时间戳剧本分镜】+【音频设计】

【全局设定】必备模块：

  • 基础环境与质感（场景+强调物理真实感）
  • 视觉风格（风格流派+色调+质感）
  • 镜头语言（运镜方式+节奏）
  • 主体造型（主角描述）
  • 表演核心（重点展现什么）
  • 禁止项（防崩坏：禁止穿模/禁止字幕/禁止版权元素等）

【时间戳剧本分镜】格式：

[00:00 - 00:08] 【段落名】—— 段落副题 动作/物理指令：具体画面、运镜、动作、物理效果 镜头潜台词：向 AI 传达的情绪/意图（可选但有效）

5.4 超长视频写法

完整提示词 = 【全局参数】+【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】

  • 【全局参数】：时长、画幅比例等（因时间长，开头再次强调）
  • 【素材描述】：素材编号（按上传顺序）+具体用途（人物/音色/动作/场景）；无素材可忽略
  • 【一句话概述】：主体+地点+事件+题材/风格+特殊运镜
  • 【具体情节描述】：分时间轴或故事线；单个分镜/时间段 = ➕正向描述（画面+运镜+动作+台词+音效）+ ➖反向描述（不要字幕/不要BGM)
  • 【全局补充】：贯穿始终的元素（机位+环境/场景特征+整体声音/氛围+光影）；再次强调不想出现的元素

帧级时间戳示例（《奶奶的菜谱》720 帧，24s):

5.5 视频延长写法

  • 方式：参考@视频1内容，延长视频 Ns(向前/向后延长）
  • 要求词：延长自然、动作衔接流畅/自然，禁止生硬切镜、禁止物体凭空出现
  • 每段延长时长建议标注（如“延长5s 10-15s”)，支持多次套娃（延长1-1 → 延长1-2 → 延长1-3）

示例：

参考@视频1的内容，延长视频5s向后延长。要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。@图1壮汉战士突然察觉到异样，停下脚步，眼神变得锐利。他迅速摆出防御姿态，紧紧盯着前方。

跨场景延长示例（遮罩转场）:

参考@视频1的内容，延长视频10s延长续写。要求需要在切镜处使用“遮罩转场”转场（禁止生硬切镜、禁止物体凭空出现）。镜头A展示正在防御的@图1壮汉战士（近景），一阵风吹过，一片正常大小的落叶飘向镜头，树叶完全遮挡镜头导致全屏变暗；随后镜头穿过树叶拉开，直接显现出下一个场景：@图2的年轻游侠正靠在一棵树旁边，正举起弓箭瞄准。要求必须自然切换场景。由战士的近景自然切换为游侠的中景。

5.6 智能编辑/高级编辑/视频编辑写法

A. 可填内容（常规提示词）:

必填词汇：1. 编辑视频里的xx 2. 增加/加上 3. 删除/去掉 4. 修改/替换/改成 5. 其他相关描述

第06章六、亮点功能详解

🕒 视频延长 创作不断档

  • 单次最高 30s 内延长；多次套娃延长最长 60s

✌️ 超长视频最长达 180 秒

  • 超长视频模式最多生成 180s

🎯 时间戳文本控制

  • 文本指定具体时间戳，精确到秒；控制动作演变与场景转场，剧本级精准还原
  • 用法：提示词中写 [00:00-00:08] 等时间段+动作指令；或第 N 秒转身/第 N 秒转场

🌍 打破语言边界

  • 重点优化：中文、英语、西班牙语、印尼语、马来语
  • 覆盖：泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语
  • 优化对白发音准确率、生僻字误读、断句自然；口型与多语种语音配合
  • 用法：母语撰写 Prompt；角色说话直接写目标语言台词
  • 场景：出海营销本土化广告、全球创作者母语表达、多语言短片

🔇 去除无关字幕与BGM

  • 用法：提示词加“纯净视频，无字幕，无背景音乐”
  • 场景：纯净空镜素材积累、高定制化商业广告/MV(干净底片）、沉浸式视觉背景/屏保
  • 示例（电商穿搭，全程静音）:
竖版9:16电商穿搭展示视频，纯白极简无缝影棚背景，固定分栏版式全程保持一致：画面左侧垂直排列3个带细黑色圆角边框的矩形模块，每个模块顶部是带左右短横线装饰的黑色衬线数字编号（1、2、3），模块内放置对应穿搭单品平铺图，单品下方标注小字“1x”；画面右侧是年轻女性模特全身站立穿搭实景展示，全身平视固定机位，浅柔和影棚均匀布光，无硬阴影，服装面料纹理清晰细腻，模特保持自然优雅站姿，有轻微的抬手整理衣物、调整站姿等舒缓动态，整体风格干净高级，符合女装电商带货审美。参考图作为风格和版式锚定，保持分栏边框样式、字体排版、光影质感全程统一，视频帧率24fps。全程禁止出现任何文字字幕、标语、水印、logo、额外标注，全程无背景音乐BGM、无人声旁白、无环境杂音，只有完全静音的纯视觉画面，镜头全程固定不推拉摇移，版式结构全程保持不变。

🌟 基础生成效果全面优化

  • 大幅弱化“AI感”，更逼真物理质感；切镜一致性显著提升；解锁大量复杂长尾动作
  • 案例对比（2.5 vs 2.0）:VRMMORPG 亡灵巫师 Boss 登场 CG、2D 手绘独立游戏宣传片、科普连环画转视频——2.5 在风格/氛围/特效/BGM 节奏上全面优于 2.0

🚀 多模态参考全面优化（四大维度）

  1. 创意与元素的解构：分离BGM、迁移创意、无缝转场、多宫格分镜——无损移除BGM仅留人声与字幕；精准抓取迁移镜头语言和情绪氛围
  2. 精细编辑的掌控：局部编辑、空间推理——局部消除和编辑、空间机位修改，自动补全画面外未见细节
  3. 感官维度的拓宽：音色参考、多人参考——精准复刻声音情绪；解决群像戏时空一致性与换脸错位
  4. 影视工业的深化：绿幕编辑、白模控制——白模精准调度复杂运镜与角色动态，绿幕轻松完成背景替换与特效合成

🎵 分离/移除背景音乐（BGM)

  • 用法：提示词中要求删除音乐背景音仅留人声，保留原画面字幕等元素
  • 示例：
去除@视频1中的背景音乐，保留清晰的人声。同时参考@图1@图2@图3给视频加入阳光照进房间的效果，保证自然明亮，真实感。并去除掉视频中的水印。

✨ 迁移创意

  • 三个层次：1）精准镜头语言提取（运镜轨迹：推拉摇移/手持摇晃）;2）深层情绪与氛围复刻（色彩逻辑/情绪基调/意境）;3）爆款“网感逻辑”迁移（视觉节奏/排版逻辑）
  • 用法：@参考视频 + 详细描述要替换/迁移什么创意内容，描述内核（如可爱状态、喜剧效果）
  • 场景：爆款网感短视频（舞蹈挑战/卡点变装/热梗模仿）、广告制作（运动品牌/汽车/时尚走秀）
  • 示例：

✂️ 局部消除与编辑

  • 精准识别并移除视频中特定物体，进行去除或再编辑
  • 示例：消除左边女子和右边男子只留中间女子（动作保持不变）；消除绿色英文标题文字；时间改为月夜光影变为月光

🎥 空间视角修改

  • 三个能力：1）三维空间深度解析（理解空间关系与景深，虚拟摄像机）;2）多维视角自由重构（俯/仰/平视/特写/全景）;3）动态运镜平滑过渡（推拉摇移/环绕跟随）
  • 用法：提示词直接加镜头语言与视角指令，例如：“将平视镜头修改为从高空俯拍，镜头缓慢向下推进”、“把第三人称视角，修改为视频中人物以第一人称视角穿梭于森林中”

🎙️ 音色参考升级

  • 用法：上传参考音色音频（建议清晰无杂音人声）+ 输入需要生成的文案 + 情感指令
  • 示例：“参考@音频1说我找到了你，并保持低沉悬疑的语调”
  • 场景：微短剧与强情绪剧情（歇斯底里争吵/隐忍哭泣/高燃霸总压迫感）、商业矩阵营销与品牌专属声

👥 多人参考升级

🟩 无缝绿幕编辑

  • 1）高精细分割（复杂轮廓，干净剥离，避免残影）;2）动态场景（人物与背景相对透视/运动轨迹帧级稳定，不闪烁跳脱）
  • 用法：上传绿幕背景参考视频 + 描述替换的新场景/上传参考图。示例：“将背景替换为中世纪魔法森林，光影神秘”、“参考教室图片，将绿幕中的人物自然融入其中”

🎬 专业级白模控制

  • 1）场景结构解析；2）空间与构图锁定（前后景遮挡逻辑）;3）角色站位与运动轨迹控制（按编排“走位”表演）
  • 用法：上传 maya/blender 白模动画 + 赋予材质/光影/角色设定

  • 注意：社区反馈白模渲染效果仍不理想、与原视频偏差大（2.5 初版）
