五个开源 TTS 引擎，哪种话该交给谁

我把 CPM2、FireRed、Vox CPMSpeech、IndexTTS 2.5、Qwen3 这五个能在家用显卡上跑起来的开源语音模型，放在同一批文案上听了一遍：五类中文方言、五种外语、英语数字读法、情绪控制，外加本地耗时和显存。

结论只有一句：它们都能出声，但「像不像我」「方言对不对」「数字读得准不准」这三件事经常互相打架，没有全能选手，只能按场景挑。下面直接给选择表，不绕弯。

情绪克隆这轮没成 参考音：我自己的中文录音 RTX 4070 Ti SUPER 16G 结论只对本次条件有效
照着选 各引擎脾气 方言 外语 英语数字 能照抄的参数 耗时与显存 情绪 边界

02 每个引擎的脾气同样是开源模型，强项完全不在一个方向。

CPM2 外语稳妥

Vox CPMSpeech · 支持可控克隆与 Hi-Fi 两档

强在
本人音色的外语自然句；葡语、法语这组听感最舒服；韩语做正式旁白；上海话用「可控克隆 + 不加指令」明确成功。
弱在
情绪克隆这批音色明显跑偏；上海话 Hi-Fi + 本人参考读数字会变成普通话；加了方言指令反而混说。
拿来做什么
普通多语配音第一顺位；葡 / 法 / 韩正式腔优先。

Qwen3 Base 方言最全

Qwen3 TTS · 另有内置声线与设计版

强在
韩语像日常聊天；日语 / 葡语 / 俄语自然句可接受；山东话、河南话是唯一能用的；英语数字展开版被认可。
弱在
英语原文数字输入有中英混读反例；法语不如 CPM2；方言用公开参考时，音色就不是我了。
拿来做什么
日常韩语；山东 / 河南方言；允许另存朗读稿的英语；显存吃紧时的备选。

FireRed Base 上海话最强

FireRedTTS3 · 方言列表最细

强在
上海话 + 本人音色 + 数字展开明确成功，数字原文版也成；粤语组效果好；日语可接受；俄语这组更清晰。
弱在
葡语这条内容被否决、含糊；韩语 / 法语咬字不如 CPM2；本次推理显存峰值偏高。
拿来做什么
本人上海话、粤语首选；日语 / 俄语备选。别把它和 Instruct 版混着比。

IndexTTS 2.5 方言不行

Index · 情绪控制接口最全

强在
旧英语数字原文组评价好；日语自然句本人音色、速度快。
弱在
五类方言基本都读成普通话或带口音普通话；情绪控制这批音色改变、目标情绪不明显。
拿来做什么
英语数字原文的先试基线；日语备选。方言和本人情绪克隆不优先。

FireRed Instruct 只做新音色

提示词驱动的语气版本

强在
普通话「兴奋分享」设计版，是这轮听过最贴合语气要求的一条。
弱在
愤怒 / 悲伤不明显或语速不对；上海话组读普通话、疑似吞字；设计版没有证明能保留本人音色。
拿来做什么
不要求「像我」、只想快速造一个新声线讲兴奋内容时用。

Qwen3 内置 / 设计 不算克隆

CustomVoice 固定声线 · VoiceDesign 提示词造声线

强在
Eric 成都声线归在四川话成功组；设计版上海话成功；普通话低沉、慢速能听出来。
弱在
愤怒 / 悲伤 / 兴奋目标不稳定；内置声线不是我，不能拿来比相似度；设计版山东变陕西。
拿来做什么
允许换声线的场景。绝不能当「本人克隆已通过」。

03 方言：说对 ≠ 像我这是最容易误解的一块：方言对了，声音往往已经不是我了。

五种方言跑下来，只有三种能同时满足「方言正确」和「音色像我」，而且都要特定配置：上海话（FireRed Base、CPM2 可控克隆）、粤语（FireRed、CPM2）。四川话、山东话、河南话能说，但音色是参考音或内置声线的，不是我的。

04 外语：先看想要什么语气同一句话、同一个参考音，几家都能听懂，差别在语气和咬字。

五种外语的自然句我都听了同内容多版本。凡是标「我的音色」的，都是听感确认像本人；听不清内容的语言（葡、俄、法），只记录跨模型听评，不冒充母语者逐字校对。

语言听感结论怎么选要记住的区别
日语四引擎这句都是「我的音色、听着可以」Index / FireRed / CPM2 / Qwen3 都能用，按耗时和显存取舍只验证了自然句，长文另算
葡萄牙语CPM2 自然清晰、有抑扬顿挫；Qwen 同内容但不如它CPM2 优先，Qwen 备选FireRed 这条内容被否定，含糊且不对
韩语三条内容一致、都是本人音色；Qwen 像家常话，CPM2 像正式演讲日常交谈用 Qwen，正式旁白用 CPM2FireRed 较含糊，别用
俄语三条都可接受、内容一致；FireRed 这组更清晰要快选 CPM2，要省显存选 Qwen，要清晰选 FireRed只是本组取舍，不是语种排名
法语CPM2 最自然；FireRed 咬字别扭；Qwen 接近 FireRedCPM2Qwen 这条没单独确认音色相似度

05 英语数字：三种处境，三种解法这是实测里最实用的一块，数字读错是最容易被观众听出来的。

  • 原文数字不能改：IndexTTS 2.5 当先试基线（旧英文组评价好，新旧基线逐字节复现）。但它不保证任意数字都对。
  • 允许另存一份朗读稿：Qwen3 Base + 数字/缩写全展开，数字全部用英语读出来，这条被确认没问题。展示稿仍可保留数字，两套稿分开存。
  • 原文要留、但可以换声音：Qwen3 / CPM2 换 8.08 秒官方英语参考后数字全英语；FireRed 同参考版也明显改善、能自然听懂。代价是说话人已经不是我了。
反面教材：只换音色嵌入、原文不改的 Qwen 版本，仍然中英混读。这类配置不能算「数字读法修好了」。
「毕竟你改了文案，现在没什么问题……但有些文案，不适合改成英文该咋办？」 —— 英语数字展开版通过时我留下的疑问，也是我建议两套稿分开存的原因

08 情绪：这轮先别指望「像我」和「情绪到位」在现有开源方案里还没同时成立。

24 条情绪样本里听了 17 条就停了。四个模型在愤怒、低沉悲伤、兴奋分享三个目标上，要么音色变了，要么情绪只是「有点着急」「有点像分享好消息」，达不到要求。

「md 烦死了！效果都不行，音色也变了」 —— 英语愤怒组听到 IndexTTS 那条时的原话

唯一的正面特例是 FireRed Instruct 的普通话「兴奋分享」设计版：语气确实是这轮里最贴的一句。但它用的是提示词造出来的新音色、没有参考音，所以只能说明「它能做语气」，不能说明「它保住了我的声音」。

这批情绪样本共用同一句「先别着急、检查连接……」的文案，文意本身和愤怒 / 悲伤的目标不完全匹配，这是实验设计的限制。它不推翻失败结论，但也说明这一块还没测到位——所以这轮不下「模型做不到」的定论，只说「现在这套配置不行」。

09 这份结论的边界

  • 只对本次条件有效：同一句文案、同一份参考音、同一组参数。换原文、换朗读稿、换参考，结果可能反转（上海话那组已经出现过）。
  • 组级反馈 ≠ 每个版本都通过：粤语「效果不错」是模型组判断，没有逐一锁定每个变体；音色相似度也没逐条单评。
  • 非母语者听评：葡语、俄语、法语我听不懂内容，只记录跨模型听感对比，不做母语逐字校验。
  • 硬件是 16G 单卡：耗时和显存只代表 RTX 4070 Ti SUPER 16G 上的这一次，不是所有机器。
  • 不做「最佳参数」：这些值是本次真实调用值，不是普遍最优。Vox 的 Hi-Fi、可控克隆，Qwen 的 Base、内置、设计，是三条不同的音色路径，不能互相套用。
