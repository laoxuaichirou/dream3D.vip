Edge / Chrome / Chromium 手动安装

  1. 下载 ZIP 并解压到一个固定文件夹。
  2. Edge 打开 edge://extensions/；Chrome 打开 chrome://extensions/。
  3. 开启“开发人员模式”或“开发者模式”，点击“加载解压缩的扩展”。
  4. 选择刚才解压、包含 manifest.json 的文件夹。
