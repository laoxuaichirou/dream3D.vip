Gary Prompt 隐私政策

生效日期：2026 年 8 月 10 日

Gary Prompt 是本地运行的浏览器扩展，不包含 Gary Prompt 作者运营的后端服务。本政策说明扩展如何在设备本地处理数据，以及何时把用户主动提交的内容直接发送给用户选择的第三方 API 服务商。

本地保存的数据

  • API 服务商、接口地址、模型、界面语言和输出设置。
  • 用户填写的 API Key。
  • 用户创建的自定义 Skill。
  • 最近 20 条生成记录及对应文字输入。
  • 用户对数据处理说明的同意状态。

这些内容保存在浏览器的扩展本地存储中，不会发送给 Gary Prompt 作者或 dream3d.vip。卸载扩展通常会清除这些本地数据；用户也可以在扩展中清空历史并删除自定义内容。

发送给第三方 API 的内容

只有在用户主动点击生成、解析、转换、测试连接或获取模型后，扩展才会连接用户配置的 API 地址。根据任务类型，发送内容可能包括：API Key、模型名称、当前 Skill 指令、用户输入、生成参数，以及经过本地压缩的图片或视频关键帧。数据直接从浏览器发送至所选服务商，不经过 Gary Prompt 作者的服务器。

图片与视频

图片会在浏览器本地缩放和压缩。视频会在浏览器本地解码并抽取关键帧；Gary Prompt 不会把完整视频发送给所选 API。生成历史不保存原始图片、视频或抽帧内容。

权限

扩展只在用户准备调用某个 API 时请求访问该 API 域名。访问当前网页输入框的权限只在用户主动点击“插入网页”时使用。扩展不会在后台读取浏览历史或网页内容。

第三方服务与邀请链接

第三方 API 对数据的处理、保留和安全措施由相应服务商的政策决定。部分“获取 API Key”入口包含作者邀请链接，点击或注册可能为作者带来奖励；这些链接只会在用户主动点击后打开，不会后台跳转或修改其他网页链接。

安全

API 通信必须使用 HTTPS，本机 localhost/127.0.0.1 开发接口除外。浏览器扩展存储不是加密保险库，建议使用可撤销且设置额度限制的 API Key，不要在公共设备上保存密钥。

联系与变更

如对本政策有疑问，请通过 dream3d.vip 联系作者。本政策发生重要变化时，会在扩展界面或网站上显著说明，并在需要时重新征得用户同意。

Gary Prompt Privacy Policy

Effective: August 10, 2026

Gary Prompt is a locally running browser extension and has no backend operated by its author. Settings, API keys, custom Skills, consent state, and the latest 20 text-based history entries are stored in local extension storage and are not sent to the author or dream3d.vip.

Only after a user starts an API-related action may the extension send the selected Skill instructions, user input, generation settings, API key, compressed images, or locally sampled video frames directly to the API endpoint configured by the user. Full videos are not uploaded by Gary Prompt. The API provider's own privacy and retention terms apply.

The extension requests access to an API domain only when the user attempts to use that endpoint. Access to a webpage input field is used only after the user clicks Insert into page. Gary Prompt does not read browsing history or webpage content in the background.

Some Get API Key buttons are author referral links and may reward the author. They open only after an explicit user click and never rewrite links in the background. API traffic must use HTTPS, except local development endpoints on localhost or 127.0.0.1.

Questions can be submitted through dream3d.vip.
